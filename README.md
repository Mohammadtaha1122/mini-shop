## mini Shop Page

This project is built with **React** and **TailwindCSS**, featuring a fully responsive design that adapts smoothly to both desktop and mobile screens.  
The navigation includes a mobile-friendly hamburger menu with soft open/close animations and a dark overlay effect.  

- 🔗 Products are dynamically fetched from an **API**.  
- 📱 Lighthouse (Mobile): SEO score `83`, Performance score `35`.  
- 💻 Lighthouse (Desktop): SEO score `83`, Performance score `69`.  
- 🎨 UI is built with TailwindCSS utilities for a clean and modern look.  


This repo mainly focuses on **responsive UI/UX** and experimenting with **performance & SEO metrics** using Lighthouse in Chrome DevTools.
